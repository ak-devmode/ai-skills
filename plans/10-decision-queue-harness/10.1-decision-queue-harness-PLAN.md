- **Type**: AI
- **Input**: scope §4.1, §7
- **Action**: JSON Schema for a packet: common fields + per-type payload (`data-model`, `generic`; `ui` reserved for 10.4); reply template with lane tag

### Task 1.2: `packet.py` and `door.py`
- **Type**: AI
- **Input**: 1.1
- **Action**: `packet.py new|close|stale|event|check-reply`, local outbox always, POST when `DECISION_QUEUE_URL` set, never fails the caller on a dead queue (writes outbox, prints `queue: unreachable`); `door.py classify --repo --range` from `.one-way-doors` + defaults; promote-only
- **Output**: `ai-skills/scripts/packet.py`, `ai-skills/scripts/door.py`, defaults file, tests
- **Acceptance**: unit tests: offline path, wrong-tag reply refused, floor path forces one-way, agent `two-way` on a floor path comes back `one-way`

- **Type**: AI
- **Input**: 1.1, homelab PG
- **Action**: Python + uv service in `dev-workbench/queue/`: POST /packets, POST /events, GET / newest-first with packet / card / ticker densities, GET /p/<id>, "since you last looked" grouping, editable prefilled reply + copy; create `decision_queue` DB (scope §7 creates, once approved); systemd unit + install.sh wiring; bind tailnet
- **Output**: `dev-workbench/queue/`, `config/systemd/decision-queue.service`
- **Acceptance**: service tests green; `curl` POST from the MBA over the tailnet returns 201 and the card renders

- **Input**: 1.3
