## Phase 2: Review and verify re-pointed at decisions

### Task 2.1: Exit rule
- **Type**: AI
- **Input**: `review/scripts/review.py`, baseline §3
- **Action**: stop + packet when a round's blocking findings land only on files already hit in the unit, or on any `local-maxima` finding; fresh blocking findings on new files keep looping
- **Output**: review.py + SKILL.md §5.1
- **Acceptance**: tests: re-hit-only round → stop; new-file blocking → continue; local-maxima → stop

### Task 2.2: Lineage fix (TO-DO P1)
- **Type**: AI
- **Input**: ai-skills TO-DO `review_lineage`
- **Action**: continue a lineage only when the range holds a fix named by an earlier disposition, or `--continues <id>`
- **Output**: review.py
- **Acceptance**: test: u2 after u1's fix range → round 1; fix re-review → previous + 1

### Task 2.3: `--reframed` disposition (TO-DO)
- **Type**: AI
- **Input**: ai-skills TO-DO `[CASCADE]` outcome
- **Action**: add `dispose --reframed "<TO-DO item>" --by <user>` allowed at any round on a `[CASCADE]` file; gate treats it like a deferral; warn when a `--fixed` sha was reverted
- **Output**: review.py, verdict-gate.py
- **Acceptance**: tests per the TO-DO text

### Task 2.4: Packets from review and verify
- **Type**: AI
- **Input**: 2.1, 10.1 `packet.py`
- **Action**: `[CASCADE]`, `[CONVERGENCE]`, the exit-rule stop and `/verify`'s run-cap STOP emit a decision packet with the findings as payload; inline question only when no queue URL
- **Output**: review.py, verify SKILL.md §3.9
- **Acceptance**: a fixture review produces a packet JSON matching the schema

### Task 2.R: Review
- **Type**: AI
- **Action**: `/review` on each repo's `base..HEAD` (base from `closeout-prep.md`), with
  `--scope`/`--unit 10.2`; disposition every finding ID (/plan §6.8)
- **Acceptance**: range non-empty; every finding `fixed <sha>`, `rejected <reason>`, `accepted "<nit>"`
  or, past round 3 of its lineage, `deferred "<TO-DO item>"`; on a SHIP,
  `review.py accept --by "<owner> (standing policy)"` (/review §5.1)

### Task 2.V: Verify
- **Type**: AI
- **Action**: `/verify 10.2` — runs the rows this phase owns in `finish-conditions.md`;
  mark Done only through `plans-index.py status` (/plan §6.8)
- **Acceptance**: gate verdict recorded in `artifacts/verify-10.2-report.md`
