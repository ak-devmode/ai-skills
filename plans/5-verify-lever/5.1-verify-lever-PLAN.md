## Phase 1: Contracts + deterministic scripts

### Task 1.1: Contract documents
- **Type**: AI+HUMAN_REVIEW
- **Input**: scope.md §4.1; brief §3.1–3.5; research §4a (feature-map shape, CLI rules)
- **Action**: write the contracts as templates under `templates/`, examples under
  `templates/examples/` (never inside a template):
  - finish-condition table (`check_id`, command or `judge`, rung, unreachable-allowed + reason, evidence; revisioned)
  - verdict TSV (`run_id`, `check_id`, SHA(s), deployed version, finish-table revision, judge line; latest run per check decides)
  - gate semantics (one-way authority; required fail/inconclusive blocks; declared-unreachable only; stale-SHA rejection)
  - review dispositions (raw findings with stable IDs; every ID covered)
  - evidence placement (class-A private only; permitted public verdict fields)
  - feature map (index with status + evidence; four-H2 feature file)
  - adapter (doctor / env handle / verbs; CLI rules; exit codes 0/1/2/3)
- **Output**: `templates/finish-conditions.md.template`, `templates/verify-verdict.tsv.template`,
  `templates/review-dispositions.tsv.template`, `templates/feature-map/`, `templates/verify-adapter.md`,
  `templates/examples/`
- **Acceptance**: every contract names its reader and writer; a test generates each file from
  its template and finds no example rows

### Task 1.2: `scripts/resolve-identifiers.py`
- **Type**: AI
- **Action**: v1 kinds only — env var, SSM path, proto field, route — each against its
  authoritative declaration files, namespace-aware; comment/fixture hits don't count; a new
  declaration in the same diff resolves. Prints `found · resolved · unsupported kinds`.
- **Output**: script + `scripts/README.md` entry
- **Acceptance**: table-driven tests incl. counterexamples — name only in a comment (fails),
  name in an unrelated proto message (fails), real new declaration in the diff (passes),
  planted fake env var (fails); unsupported kind reported, never green

### Task 1.3: `scripts/verify-run.py` (runner)
- **Type**: AI
- **Action**: execute each finish-table row's command; write evidence rows (command, exit,
  output hash, ts, SHA, deployed version for live rows, finish-table revision, run_id);
  non-executable rows → `inconclusive` + reason; refuse class-A evidence under a public repo.
- **Output**: script + `scripts/README.md` entry
- **Acceptance**: self-test — pass, fail, non-executable, and public-repo refusal cases

### Task 1.4: `scripts/verdict-gate.py` + index enforcement
- **Type**: AI
- **Action**: gate over the latest run per `check_id`; required fail/inconclusive blocks;
  unreachable only where declared; stale SHA rejected. `plans-index.py` refuses to mark a
  phase Done unless the gate passes; judge ≠ codex appends `⚠ judge: <fallback>` to the phase
  status, cleared by a later codex verdict. Advisory mode flag (warn + mark, don't block).
- **Output**: script, `plans-index.py` change, `scripts/README.md` entries
- **Acceptance**: table-driven self-test — pass / missing / under-rung / fail-then-fixed
  (clears) / downgraded-to-inconclusive (blocks) / undeclared-unreachable (blocks) / stale
  SHA (rejected) / fallback marker set then cleared
