## Phase 1: Contracts + deterministic scripts

### Task 1.1: Contract documents
- **Type**: AI+HUMAN_REVIEW
- **Input**: scope.md §4.1; brief §3.1–3.5; research §4a (feature-map shape, CLI rules)
- **Action**: write the five contracts — finish-condition table, verdict TSV, review
  disposition TSV, feature-map (index with status + evidence, four-H2 feature file),
  adapter (doctor / env handle / verbs, CLI rules, exit codes) — as templates under
  `templates/` (shared by /scope, /plan, /verify, /closeout). Include one filled example
  each; examples live inside HTML comments so a copied template carries no fake rows
  (the ledger-template lesson).
- **Output**: `templates/finish-conditions.md.template`, `templates/verify-verdict.tsv.template`,
  `templates/review-dispositions.tsv.template`, `templates/feature-map/` (README + feature file),
  `templates/verify-adapter.md`
- **Acceptance**: every contract names its reader and writer; no example row survives a copy

### Task 1.2: `scripts/resolve-identifiers.py` (invented-reality check)
- **Type**: AI
- **Input**: a diff range; the repo + CROSS-REPO.md Pattern Sources/Consumers
- **Action**: extract external identifiers the diff introduces (env vars, SSM paths, proto
  fields, routes, table/column names, sibling-repo paths); resolve each against its source of
  truth by content-grep on `origin/<trunk>`; report unresolved ones as
  `expected · found · where · next`. Start with the identifier kinds that caused real misses;
  add kinds on second sighting.
- **Output**: script + `scripts/README.md` entry (contract + exit codes)
- **Acceptance**: fails loud on a planted fake env var and a fake proto field; passes on a
  clean diff; exits non-zero when it resolves nothing it was asked about (no silent green)

### Task 1.3: `scripts/verdict-gate.py`
- **Type**: AI
- **Input**: finish-condition table + verdict TSV for a phase
- **Action**: exit non-zero when the verdict is missing, has a finish-table row with no verdict
  row, a row below its required rung, or any `fail`. `inconclusive` / `verified-unreachable`
  pass the gate but are listed as lever candidates.
- **Output**: script + `scripts/README.md` entry
- **Acceptance**: table-driven self-test over pass / missing / under-rung / fail cases
