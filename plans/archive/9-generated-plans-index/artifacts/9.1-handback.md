## 2. What 9.3 must know before cutover

2.1 **Mode switch is the README line.** `plans/README.md` → `**Index render:** bot`
or `local`. No line = **legacy mode**: the script edits PLANS-INDEX.md in place
exactly as before, so every graph keeps working until 9.3 adds the line. Legacy
mode is a bridge; drop it once all four graphs are cut over.

2.2 **Cutover order per graph:** run `migrate` (idempotent — a second run writes
nothing), add the README line, `render`, `check`, commit as one unit. `render`
before `migrate` refuses (exit 2, "not migrated").

2.3 **`render` refuses to lose rows.** If a rendered row has no record it exits 1;
`--allow-loss` overrides. A concurrent hand edit landed after `migrate` trips this
— re-run `migrate`, not `--allow-loss`.

## 3. Behaviour decisions made in this lane

3.1 **Plan-file paths that don't exist yet resolve to their folder.**
`3-alpha/3.1-x-PLAN.md` lands in `3-alpha/`'s record even before the plan file
is written — otherwise every pre-registered plan row went loose.

3.2 **`move` repoints after a hand `mv`.** If the folder was already moved by
hand, `move` still rewrites the Folder cells (old path with and without the
`archive/` component), so verify-archive doesn't fail on a stale cell.

3.3 **`move --folder` re-homes a loose row** into the destination folder's record
when the folder's kind matches `--to`. Legacy-mode `move` onto an already-placed
row repoints it in place (no reorder).

3.4 **Archive guard runs in both modes.** kalpa-docs: the kalpa-orchestra
`projects/*/BACKLOG.md` cell must not still read `scoped(N)`; `--force REASON`
overrides.

3.5 **plans-publish in bot mode** drops `PLANS-INDEX.md` and `archive/INDEX.md`
from the staged paths with a stderr note; if nothing remains it prints
"nothing to publish" and exits 0. The bot owns the render commit.

3.6 **claim-scope-number** in records mode reads a fresh `render --stdout`
locally, `archive/INDEX.md` + `ls-tree` folder names on origin, and counts a
branch's number only when that branch has the `N-*` folder (`ls-tree` of
`plans/` and `plans/archive/`) — a number mentioned only in a branch's index
render no longer claims.

3.7 **scan-archive-drift** reads a scope's N.P rows from its record block when
one exists, otherwise the hand table — never both (no double count).

3.8 **Gate mode** (`verify_lib.gate_mode`) reads `**Gate mode:**` from
`plans/README.md` first, then falls back to PLANS-INDEX.md — because the index
becomes generated and can't carry a hand-written header line.

3.9 **Operating Contract rule 5 holds:** `render` and `check` never call
verdict-gate.py; only `status`/`validate` do.

3.10 **Skill prose:** /scope now tells a graph with no index to start with a
README holding `**Index render:** local`. /prd registers via
`claim-scope-number.sh` + `plans-index.py add` (root-level PRD file → loose row;
folder-form PRD → its folder record). markdown-style §11.7.6 states the rule.
